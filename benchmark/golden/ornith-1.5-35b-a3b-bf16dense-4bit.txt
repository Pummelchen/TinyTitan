A mutex (mutual exclusion) is a synchronization primitive used to protect shared resources from being accessed concurrently by multiple threads. It ensures that only one thread can access the resource at a time. You would use a mutex when you need to prevent race conditions, such as when multiple threads are modifying shared data structures like a linked list.
