# AUD-0042 — checked raw-layer size in the compressed writer geometry

Commit: `audit(0042): …` (see `git log --grep 'audit(0042)'`)

Baseline: detached `fd3d3fca` (after AUD-0041).

## Defect proved before the fix

`CompressedExpertLayerGeometry.rawBytes` was

```swift
public var rawBytes: UInt64 { expertStride * UInt64(expertsPerLayer) }
```

`validate()` bounded each factor (`expertsPerLayer > 0`, `expertStride > 0` and
`<= Int.max`) but never the product. `write()` then calls
`try geometry.validate()` and immediately compares `sourceSize ==
geometry.rawBytes`, so a geometry of `stride = Int.max, experts = 3` passes
validation and traps at `*` in `write` — after the source file has been opened,
before the size check can refuse it.

### RED (tests added before the fix)


## Fix

`sources/TinyTitanRepack/Core/Writing/CompressedExpertLayerWriter.swift`

- `validate()` computes `expertStride * expertsPerLayer` with
  `multipliedReportingOverflow` after the per-factor guards and throws
  `RepackError.configurationInvalid` ("… overflow the raw layer size"). It runs
  before `write` opens the source file or allocates the expert buffer.
- `rawBytes` uses the same checked product and documents its non-valid
  saturation: `UInt64.max` when the product cannot fit, `0` when
  `expertsPerLayer <= 0`. A caller that skipped `validate()` therefore fails its
  size comparison (no file is 16 EiB) instead of trapping.
- Valid geometry returns exactly the old product; the writer's roundtrip tests
  still compare every expert's bytes with the source.

## Tests added

`tests/TinyTitanRepack/Core/Writing/CompressedExpertLayerWriterTests.swift`:

- `stride = UInt64(Int.max), experts = 3` → `validate()` throws `RepackError`;
- the same geometry's `rawBytes` returns `UInt64.max` rather than trapping;
- a large valid product (`1 << 40` × `1 << 20`) returns exactly `1 << 60`;
- the existing split/whole layer writer tests (normal writes byte-identical)
  pass unchanged.

`swift test --no-parallel --filter CompressedExpertLayerWriterTests`: **8 tests**,
pass.

## Residual risk

- `rawBytes` remains a total property with a documented saturation for a
  geometry that was never validated; `write()` always validates first, and a
  direct property caller gets a value no real file can match.
- The change does not alter any written byte: the checked product equals the
  unchecked one for every valid geometry.
