# AUD-0055 — refuse a zero head dimension

Commit: `audit(0055): …` (see `git log --grep 'audit(0055)'`)

Baseline: detached `ef18d8b6` (after AUD-0054).

## Defect proved before the fix

`Inkling2Arch.archInfo` computed the attention scale from metadata:

```swift
attentionScale: 1 / Double(p.headDim).squareRoot()
```

`headDim = 0` gives `1 / 0 = +infinity`; a negative value gives NaN.
`ArchInfo` was still built and returned, so a manifest with an infinite
attention scale could be planned/written instead of refusing the model. (The
line the earlier finding named as `Inkling2GGUFArch.swift:110` is
`sources/TinyTitanRepack/Core/Format/Inkling2Arch.swift:110`; the fix belongs in
the shared builder both readers use.)

### RED (tests added before the fix)

```
swift test --no-parallel --filter zeroHeadDimensionIsRefused
Expectation failed: an error was expected but none was thrown   (headDim 0)
Expectation failed: an error was expected but none was thrown   (headDim -8)
Expectation failed: an error was expected but none was thrown   (GGUF key_length 0)
```

No trap; the failure is the returned `ArchInfo` with a non-finite scale.

## Fix

`sources/TinyTitanRepack/Core/Format/Inkling2Arch.swift`

After the loop/local-layer guards:

```swift
guard p.headDim > 0 else {
    throw RepackError.configurationInvalid(
        detail: "Inkling 2 head dimension \(p.headDim) must be positive")
}
```

Both `Inkling2GGUFArch` and `Inkling2CheckpointArch` build through this function,
so both sources are covered. Valid models are unchanged: the fixture's
`headDim = 8` still yields `1 / sqrt(8)` and `isFinite`.

## Residual risk

- Only the divisor of the scale (`headDim`) is refused here, as scoped. A zero
  `heads`/`kvHeads`/`hiddenSize` does not make this scale non-finite; whether
  those are valid geometries is the model's own contract, not this division's.
- A positive but huge `headDim` produces a tiny but finite scale (no trap); the
  architecture's size arithmetic is checked elsewhere (AUD-0039/0054).
