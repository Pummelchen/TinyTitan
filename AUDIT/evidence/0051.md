# Audit 0051 — the CLI tests skipped by printing, not by skipping

## Finding: confirmed

`ClientCLITests` gated its two real-client tests in the body:

    guard let codex = binary("codex") else {
        print("codex not installed; skipping")
        return
    }

Swift Testing reported that as **passed** with zero assertions. When a
half-installed Homebrew `codex` existed (its node could not load
`libsimdjson.34`), the guard passed, the CLI ran, and the suite failed with
`requests.isEmpty` — an environment failure unrelated to the server. Both
outcomes were observed in the previous cluster run: the first full suite
printed the skip and passed; a rerun during the package install failed on the
broken shim.

## Change

`tests/TinyTitanServer/ClientCLITests.swift`:

- `cliIsUsable(at:timeout:)`: runs the CLI with `--version`, outputs and stdin
  nulled, and waits at most 5 s (terminating it at the deadline). A missing
  path, a non-zero exit and a hang all answer false.
- `usableCLI(name:)` resolves the fixed install path and runs that probe.
- Both tests are gated with
  `@Test(.enabled(if: usableCLI("codex")))` /
  `@Test(.enabled(if: usableCLI("claude")))`. The framework records a real skip
  when the predicate is false; the exercise itself is unchanged and is never
  skipped unconditionally.
- The body uses `try #require(binary(...))` instead of a print/return, so a
  binary that disappears between discovery and run fails with a named message
  rather than reporting a hollow pass.

## Tests

- `theCLIProbeDistinguishesBrokenFromWorking`: writes three synthetic shell
  scripts — exit 0, exit 1, and `exec sleep 30` — and asserts usable / not
  usable / not usable with a 0.2 s deadline (the stalled one is terminated).
  Also asserts a missing path is not usable. Five consecutive focused runs
  passed.
- `codexSpeaksTheResponsesAPI` and `claudeCodeSpeaksTheMessagesAPI` both ran and
  passed on this machine (the installed CLIs answer `--version`), so the gated
  path is exercised, not skipped.

Focused run: 3 tests in 1 suite passed after 16.4 s (the real CLIs dominate),
repeat runs of the probe alone passed in 0.4–0.8 s.

Gates: `swift-format`, `swiftlint` 0.65.1 `--strict`, `test-skip`, `test-hollow`
all ok (the gate recognises `.enabled(if:)` as the sanctioned skip form).

## Residual

The probe is a discovery-time decision: a CLI that is working at discovery and
broken a second later still fails the exercise, which is the right outcome for
a test that claims to exercise it. The 5 s bound may skip a CLI that is simply
very slow to start; that is preferable to hanging the suite, and the skip is
recorded by the framework rather than hidden.
